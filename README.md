Smart Budget — Personal Finance Planner

Smart Budget is a clean, responsive personal finance planner designed to help users track income, expenses, budgets, and savings goals from one simple dashboard.

Features

- Dashboard with financial overview
- Income and expense tracking
- Automatic balance calculation
- Monthly budgets by category
- Savings goals and progress tracking
- Spending categories
- Multi-currency support
- Personal name customization
- Light and dark appearance
- Responsive mobile and desktop layout
- App-like mobile navigation
- No installation required

Included Pages

- "index.html" — Dashboard
- "transactions.html" — Income and expenses
- "budget.html" — Monthly budgets
- "goals.html" — Savings goals
- "settings.html" — Personal settings and preferences

How to Use

1. Open "index.html" in a modern web browser.
2. Go to Settings and enter your name.
3. Select your preferred currency.
4. Add income and expenses from Transactions.
5. Create monthly budgets from Budget.
6. Create savings goals from Goals.
7. Return to the Dashboard to view your updated financial overview.

Data Storage

Smart Budget V1 stores your data locally in your browser using localStorage.

This means:

- Your data stays on the device/browser where you use Smart Budget.
- No account or server is required.
- Data does not automatically sync between different devices or browsers.
- Clearing browser/site data may remove your saved Smart Budget data.

Requirements

- A modern web browser such as Chrome, Edge, Safari, or Firefox.
- No database or server is required for the V1 version.

Customization

You can customize the user name, currency, and other available settings directly from the Settings page.

The product is delivered as editable HTML/CSS/JavaScript files, so developers or advanced users can further customize the design and functionality.

Important Note

Smart Budget V1 is a client-side personal finance planner. It is not a banking service, financial institution, or financial-advice product.
